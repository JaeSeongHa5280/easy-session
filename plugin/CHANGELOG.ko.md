## [0.1.34] — 2026-11-26

### 새로 생김
- **답을 받을 글인지 붙여 보내기** — 세션끼리 보내는 글의 첫 줄 맨 앞에 갈래 셋 가운데 하나가 붙습니다: **알림**(보내고 끝 — 처음 값) · **답 받기**(받는 세션에 답을 한 번 달라고 함) · **주고받기**(두 세션이 오감 — 사용자 말 없이 3번까지). 0.1.33 까지는 갈래가 없어 알리기만 할 글에도 Claude 가 답을 기다리곤 했습니다. 패널에서는 보낼 칸 아래에서 고릅니다. 보낸 뒤에는 알림으로 돌아갑니다. 전달 신호 · ➤ 로 이지 세션이 대신 보내거나 Claude 에게 보내라고 하는 글은 [알림]으로 시작합니다. 위로 보내기 안내 줄은 Claude 에게 갈래를 붙이라고 합니다.
- **Claude 가 보낼 때도 갈래** — 세션 규칙이 켜진 데스크톱 앱 세션에서 Claude 의 `SendMessage` · `send_message` 는 첫 줄에 갈래가 없을 때 · 알림인데 쉬면 알려 달라고(`notify_when_idle`) 할 때 · 사용자가 다시 말하기 전 같은 세션에 네 번째 주고받기일 때 막고 할 일을 알려 줍니다.
- **받는 쪽에 갈래를 알림** — 글을 받은 세션의 Claude 에게 갈래 한 줄이 붙습니다: 알림이면 사용자가 시키지 않는 한 보낸 세션에 답장하지 말 것, 답 받기면 [알림]으로 한 번 답할 것. 보낸 글에 갈래가 보입니다. 주고받기는 「주고받기 2/3」처럼 보낸 수가 보입니다.

## [0.1.33] — 2026-11-24

### 바뀜
- **advisor 를 바꿀 수 없을 때 알림** — 이 대화가 다른 advisor 모델로 묶여 있어 바꾸지 못하면 「Opus 5.5 로 바꿀 수 없습니다 — 이 대화는 Fable 5.2 로 묶여 있어 /compact 나 /clear 뒤에 바꿀 수 있습니다」라고 알립니다. 0.1.32 의 「이 대화는 /clear · /compact 전까지 Fable 5.2 그대로라 안 바꿨습니다」는 이지 세션이 일부러 안 바꾼 것처럼 읽혔습니다. fable 을 고를 때 묻는 카드 글도 같은 말로 바꿨습니다.

## [0.1.32] — 2026-11-24

### 바뀜
- **누를 것 덜어 내기** — 패널 줄마다 회색 단추는 그 줄의 주 동작 하나만 두고 나머지는 글 단추로 바꿨습니다. 하위 세션 줄의 손질은 **메시지** · **마무리** 두 줄로 나눴습니다. 줄 단추 「수락 N」은 둘째 줄 **받은 글 N ›** 으로 펴서 **전체 수락** 합니다. **떼어 내기** 는 빨간 테두리 경고 단추입니다.
- **보관 · 끝내기 전 묻는 카드는 누른 줄 밑** — 카드가 누른 줄 바로 밑에 뜹니다(0.1.31 은 하위 세션 칸 맨 위). 머리는 「끝내기 전에 — <제목>」으로, 무엇을 묻는지가 먼저 보입니다. 남은 글 수는 그릴 때마다 다시 셉니다.
- **위 세션 칸 「모아 둠」 줄** — 내 보고가 위 세션의 받은 칸에 아직 남아 있으면 그 수를 보입니다.
- **맨 위 단독이 하위를 열면** — 「지금」 줄이 「하위 세션 N개가 생김 — 메인 세션으로 바꿀까요?」와 **메인으로** 를 띄웁니다. 「역할 · 인계」 칸도 맨 위면 **메인으로** 입니다(0.1.31 은 「오케로 바꿀까요?」라 누르면 메인이 되는 것이 놀라웠습니다).
- **advisor 는 세션마다** — Claude Code 2.1.330 부터 이지 세션이 바꾼 advisor 는 그 세션에만 걸립니다. 설정 파일의 기본값은 그대로입니다. 기본값은 입력칸에 `/advisor <모델>` 을 직접 치면 바뀝니다. 입력창 위 칸 · [설정]은 그 세션에 건 값을 보입니다. 이 대화에 /clear · /compact 전까지 안 걸리는 바꾸기(advisor 가 이미 켜진 대화에서 모델끼리)는 앞 값으로 되돌리고 알립니다 — 대화에 `/advisor` 줄이 둘 남습니다.
- **패널 첫 그림은 보관 세션을 뒤에** — 패널을 처음 그릴 때는 보관된 세션 기록을 읽지 않습니다. 그린 뒤 한 번 읽어 다시 그립니다. 첫 그림에서 보관된 하위 줄이 잠깐 비어 보일 수 있습니다.

### 고침
- **advisor 를 골라도 칸이 안 바뀜 · 알림이 깨짐** — Claude Code 2.1.330 에서 고른 값이 칸에 안 남았습니다. 알림은 「advisor 를 Opus 5.5 for this session — run /advisor … 로 바꿨습니다」처럼 나왔습니다.
- **마우스 올림 설명이 겹쳐 뜨고 안 사라짐** — 입력창 위 줄 · 패널의 설명 칩을 이지 컴팩트와 같은 꼴로 고쳐, 단추를 누른 뒤 남거나 여럿이 겹치지 않게 했습니다.
- **하위 줄 끝내기 · 보관이 반응 없어 보임** — 묻는 카드가 칸 맨 위에 떠 누른 자리에서 안 보였습니다(위 「누른 줄 밑」). 누름마다 자료 폴더 `diag/pane-events.json` 에 한 줄을 남깁니다(화면엔 안 보임).

## [0.1.31] — 2026-11-23

### 새로 생김
- **권한 모드가 달라 버려지는 메시지 막기** — 받는 세션이 권한 무시 · 계획이고 이 세션이 그 밖 모드면 Claude 가 보낸 메시지를 앱이 붙잡았다가 몇 분 뒤 버립니다. 이제 위 세션 칸 **보내기** 는 그런 칸에서 보낼 칸 자리에 고르기 셋을 띄웁니다: **카드로 보내기** · **받는 세션을 자동으로 내리고 보내기**(일하는 중이면 그 차례가 끝난 뒤 — 30분 안에 못 내리면 글은 카드로 남김) · **이 세션을 권한 무시로 올리기**. 받는 쪽이 보고를 패널에 모아 두는 부모면 묻지 않고 카드로 갑니다. Claude 가 그런 칸에 직접 보내려 하면 막고 할 일(끝 답에 적기 · 자기가 연 하위를 자동으로 내리기 · 사용자에게 묻기)을 알려 줍니다.
- **하위 세션 권한 모드 · 하위 모두 자동으로** — 하위 세션 칸에 「권한 모드 — 자동 N · 권한 무시 M」 줄과 줄마다 모드 · 마지막 활동이 보입니다. 메인 · 오케는 그 줄 오른쪽 **하위 모두 자동으로** 로 권한 무시 하위를 자동으로 내립니다(일하는 중이면 그 차례가 끝난 뒤 · 세션 트리로만 묶인 하위는 한 번 묻고).
- **끝난 하위 정리** — 끝난 하위가 있으면 하위 세션 칸에 「끝난 하위 정리 N」 상자가 생깁니다. 이 세션이 권한 무시면 **정리** 가 고정을 풀고 한 번에 보관합니다. 그 밖 모드면 **이 세션을 권한 무시로**(앱 승인 카드 한 번) · **Claude 에게 줄마다 맡기기** 를 둡니다.
- **보관 · 끝내기 전 남은 메시지 묻기** — 다른 세션을 보관 · 끝내기 · 모두 보관하기 전에 그 세션과 남은 메시지(그 세션이 보낸 안 받은 글 · 그 세션에 보낸 안 읽힌 글)가 있으면 카드가 먼저 묻습니다 — **받고 보관** · **지우고 보관** · **남기고 보관**. 고른 것은 대화에 한 줄로 남습니다.
- **모두 수락 · 모두 거절** — 한 칸에 보낸 세션이 둘 이상이면 맨 위에 「보낸 세션 N · 글 M」과 **모두 수락**(차례 한 번) · **모두 거절**(「글 M개를 지웁니다 — 되돌릴 수 없음」으로 한 번 묻고 지움)이 생깁니다.
- **글에 나온 세션 정보 붙이기** — [설정] 「메시지」. 내가 쓴 글에 다른 세션 제목이 나오면 그 세션 한 줄(제목 · id · 권한 모드 · 도는 중인지 · 위인지 아래인지 등)을 Claude 에게 붙입니다. 처음엔 꺼짐.
- **「끝난 듯」** — 마지막 답 끝 두 줄 「남은 것」 · 「결정할 것」이 모두 「없음」인 하위 세션 줄에 「끝난 듯」과 **끝내기** 가 붙습니다. 끝남 기록은 누를 때만 씁니다.
- **맨 위 단독이 하위를 열면** — 「지금」 줄이 「오케로 바꿀까요? 맨 위라 메인이 됩니다」를 띄웁니다.

### 바뀜
- **세션 규칙(보내기 확인)** — 받는 세션이 60분 넘게 쉬었으면 한 번 멈추고 「깨우면 처음부터 다시 읽습니다」를 알립니다(같은 보내기를 다시 하면 갑니다). 살아 있는 세션 둘 이상이 같이 쓰는 제목으로 보내면 멈추고 `local_` id 로 보내 달라고 합니다.
- **보관 세션의 글** — 남기고 보관한 글의 카드엔 「보관됨」, 보낸 글 줄엔 「받는 곳 보관됨」이 붙습니다.
- **[전체 삭제] → [전체 거절]** — 모인 보고 덩이 머리 단추 이름을 낱개 **거절** 과 맞췄습니다.

### 고침
- **패널이 「Nothing to show yet」 에 머묾** — 패널을 그리다 오류가 나도 「세션 · 불러오는 중 — 곧 다시 그립니다」를 그리고 곧 다시 그립니다. 화면이 붙었는데 그림이 없으면 3 · 6 · 12초에 다시 그립니다. 까닭을 자료 폴더 `diag/pane-events.json` 에 남깁니다(최근 200줄 · 화면엔 안 보임).

버그 의뢰 2026-11-20 반영 — 세션 규칙의 쉰 세션 · 같은 제목 확인, 맨 위 단독이 하위를 열 때 「지금」 줄, 설명서의 끝남 기준 한 줄.

## [0.1.29] — 2026-11-20

### 새로 생김
- **영어 화면** — [설정] → 「화면 · advisor」 → 「언어 · Language」: 자동 · 한국어 · English. 패널 · 입력창 위 줄 · 알림 · 확인 카드와 이지 세션이 Claude 에게 붙이는 줄(입력칸 지시 글 · 관계 줄 · 「[화면]」 줄 · 규칙 줄)이 이 값을 따릅니다. 「자동」은 Claude Code 설정의 `language`(프로젝트, 그다음 사용자), 데스크톱 앱 언어, OS 언어 가운데 먼저 찾은 것을 따르고(한국어면 한국어, 아니면 영어) 30초마다 다시 봅니다. 판 단추 서랍은 고른 언어의 변경 기록을 읽습니다. 이지 세션은 두 언어로 쓴 자기 지시 글을 다 알아봅니다. 두 언어 모두 그대로인 것: 제목 꼴(`N차`) · 진행판 끝 줄(`끝:`) · 말로 시킬 때 한 줄 안내가 알아듣는 한국어 낱말 · 「결정」 꼬리표를 붙이는 `결정할 것:` 줄.
- **패널 판 단추** — 세션 패널 맨 위 줄 오른쪽 끝에 판 단추(평소 흐린 `v0.1.29`)가 생깁니다. 누르면 그 아래 서랍에서 [업데이트 확인] · [업데이트] 를 누르고 내 판보다 높은 판들의 바뀐 것을 봅니다. 확인은 누를 때만 합니다. 명령을 못 돌리면 [입력칸에 넣기] 로 Claude 에게 맡깁니다. 확인하지 못하면 까닭 글을 한 줄 전체로 두고 [다시 시도] · [명령 출력 ▸] 은 그 아래 줄에 둡니다.
- **처음 한 번 묻는 카드** — 새 자식 세션 설정 · 자식 보고 값을 한 번도 바꾸지 않았으면 데스크톱 앱 세션의 [세션 도구] 맨 위에 「추천 설정으로 시작할까요?」 카드가 한 번 뜹니다. [추천대로 켜기] 는 세 가지를 켭니다: 자식 보고를 패널에 모아 둠 · 새 자식을 고정했다 끝나면 풂 · 사이드바 그룹으로 묶음(떼어 내기 · 첫 글 ultrathink 는 꺼진 채). [앱 그대로] 는 아무것도 바꾸지 않습니다. 어느 쪽이든 누르면 다시 뜨지 않습니다. 누르기 전엔 앱 그대로입니다.
- **새 자식 세션 미리보기** — [설정] 「새 자식 세션」 맨 위에 「미리보기 · 사이드바」 칸이 생겼습니다. 부모 세션이 자식 둘을 열었을 때 지금 값으로 사이드바가 어떻게 보이는지(고정 칸 · 그룹 · 떼어 낸 자리 · 자식 보고)를 작은 그림으로 보입니다. 스위치를 바꾸면 바로 바뀝니다.
- **md 잠금** — [설정] 「md 잠금」 묶음. 「md 잠금 보기 · 풀기」 를 켜면(처음엔 꺼짐) 잠금 폴더(처음 값 `<Claude 설정 폴더>/locks`)의 잠금마다 대상 · 남은 시간 · 주인 세션 · 할 일과 [풀기] 가 보입니다. [풀기] 는 파일을 지우지 않고 끝 시각을 지금으로 고쳐 씁니다. 주인 세션이 보관됐거나 끝났으면 차례 끝에 저절로 풉니다. 채팅으로 「잠금 풀어 줘」 를 보내지 않아도 됩니다.
- **깊은 세션 트리 보기** — 하위 세션 줄 밑에 그 아래 세션이 있으면 「› 아래 N」(입력 필요가 있으면 「입력 필요 N」)이 붙습니다. 누르면 깊이만큼 들인 줄로 폅니다.
- **위 세션 칸의 메인 줄** — 메인이 바로 위 세션이 아니면 「위 세션」 칸에 「메인」 줄([보내기] · [가기])이 생깁니다.
- **`>>위` 신호** — 글 끝에 `>>위`(또는 `>>up`)를 붙이면 차례가 끝날 때 답이 바로 위 세션으로 갑니다.
- **auto 세션의 고정 · 풀기** — auto 세션이 새 자식을 고정하거나 끝난 뒤 고정을 풀어야 할 때, 같은 세션 트리 위의 bypass 세션이 그 세션 차례 끝에 대신합니다. 위에 bypass 세션이 없으면 지금처럼 그대로입니다.
- **「붙잡힐 수 있음」 한 줄** — 받는 세션의 권한 모드가 보내는 세션과 다르면 [보내기] · 「전달」 · `>>` 의 지시 글 · 알림에 한 줄이 붙습니다. 막지는 않습니다.

### 바뀜
- **메인** — 메인은 그 세션 트리의 맨 위 오케입니다. 세션 트리마다 하나라 한 PC 에 여럿일 수 있습니다. `>>메인` · 「전달」 의 메인 · 역할 칩 · 관계 줄이 모두 이 뜻을 씁니다. 하위 세션이 없는 메인은 「역할 · 인계」 에서 [오케 풀기] 로 되돌립니다.
- **입력창 보내기는 위로만** — 「전달」 은 위 세션 · 메인만 고릅니다. 신호는 `>>위` · `>>메인`(`>>up` · `>>main`)입니다. `>>이름` 은 보내지 않고 한 줄로 알립니다. 그 밖 세션에는 Claude 에게 보내 달라고 하세요.
- **떼어 낸 세션 자리** — 패널 · 사이드바에서 직접 떼어 낸 세션은 이지 세션의 세션 트리에서도 맨 위로 갑니다. 저절로 떼어 낸 새 자식은 부모 밑에 그대로 둡니다. 떼어 낸 세션이 인계하면 뒤 차수가 맨 위 자리를 이어받습니다.
- **칸 수 표** — 칸 모서리의 주황 수를 눌러도 그 칸이 펴집니다.
- **「고정 · 보관」 칸** — 지금 상태(고정 · Remote Control · 끝남 표시)는 스위치, 할 일(정리 · 제목 정리 · 보관 · 떼어 내기)은 단추입니다. Remote Control 상태를 못 읽으면 그 스위치를 흐리게 두고 「상태 못 읽음」 을 적습니다. 끝남 표시를 켤 때만 한 번 묻습니다. VS Code · 터미널의 「정리 · 끝내기」 칸도 같습니다.
- **자식 보고 값 이름** — [설정] 「자식 보고」 의 「사이드 패널에 모아 둠」 은 「패널에 모아 둠」 입니다(좁은 패널에서 잘려서).
- **「세션 트리」** — 보낸 세션 관계 줄 · [설정] 풀이 · [인계] 지시 글이 세션 사이 위아래를 「세션 트리」 라는 말로 부릅니다.
- **fable 확인 카드** — Fable 5.2 요율로 고쳤습니다. 요금은 Opus 5.5 의 2배(정가 100만 토큰당 입력 $8 · 출력 $40)입니다. 구독이면 5시간 사용량을 Opus 5.5 보다 많이 씁니다.
- **`/fork` · `/rewind` 칩** — 데스크톱 앱에서 `/fork` 설명은 「이 대화를 새 세션으로 갈라 이어 감」 입니다. `/rewind` 는 입력창에 글이 남아 있으면 넣지 않고 「입력창 글을 비운 뒤 누르세요」 를 띄웁니다.
- **[정리] 지시 글** — 저절로 붙인 고정은 bypass 세션이 풉니다. auto 세션이면 같은 세션 트리 위의 bypass 세션이 대신 풉니다. 그런 세션이 없으면 고정은 그대로입니다.
- **첫 그리기 시간 기록** — 패널을 처음 그리는 데 걸린 시간을 자료 폴더 `diag/first-draw.json` 에 적습니다(최근 50줄 · 화면엔 안 보임). 다른 세션을 눌렀을 때 패널이 늦게 뜨는 까닭을 재려는 기록입니다.
- **VS Code ultrathink 칩** — 넣었으면 채운 단추로 보입니다(VS Code 테마의 단추 색).
- **보낸 세션 관계 알리기** — VS Code · 터미널의 [설정] 풀이에 「데스크톱 앱에서만 — 여기서 바꿔도 데스크톱 세션에 적용됩니다」 를 붙였습니다.

### 고침
- **인계한 세션 보관** — auto 세션이 인계한 뒤 자기 세션을 보관하려 할 때, 아직 붙은 새 세션이 있으면 막고 먼저 `detach_session` 으로 떼라고 알립니다. 보관하면 붙은 세션도 같이 보관되기 때문입니다. bypass 세션은 지금처럼 먼저 떼고 보관합니다.
- **보낸 세션 찾기** — 받은 글의 보낸 곳이 앱 세션 번호로만 적혀 있을 때 그 세션을 못 찾아 관계 줄이 빠지던 것을 고쳤습니다.
