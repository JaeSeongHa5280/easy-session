## [0.1.29] — 2026-11-20

### 새로 생김
- **영어 화면** — [설정] → 「화면 · advisor」 → 「언어 · Language」: 자동 · 한국어 · English. 패널 · 입력창 위 줄 · 알림 · 확인 카드와 이지 세션이 Claude 에게 붙이는 줄(입력칸 지시 글 · 관계 줄 · 「[화면]」 줄 · 규칙 줄)이 이 값을 따릅니다. 「자동」은 Claude Code 설정의 `language`(프로젝트, 그다음 사용자), 데스크톱 앱 언어, OS 언어 가운데 먼저 찾은 것을 따르고(한국어면 한국어, 아니면 영어) 30초마다 다시 봅니다. 판 단추 서랍은 고른 언어의 변경 기록을 읽습니다. 이지 세션은 두 언어로 쓴 자기 지시 글을 다 알아봅니다. 두 언어 모두 그대로인 것: 제목 꼴(`N차`) · 진행판 끝 줄(`끝:`) · 말로 시킬 때 한 줄 안내가 알아듣는 한국어 낱말 · 「결정」 꼬리표를 붙이는 `결정할 것:` 줄.
- **패널 판 단추** — 세션 패널 맨 위 줄 오른쪽 끝에 판 단추(평소 흐린 `v0.1.29`)가 생깁니다. 누르면 그 아래 서랍에서 [업데이트 확인] · [업데이트] 를 누르고 내 판보다 높은 판들의 바뀐 것을 봅니다. 확인은 누를 때만 합니다. 명령을 못 돌리면 [입력칸에 넣기] 로 Claude 에게 맡깁니다. 확인하지 못하면 까닭 글을 한 줄 전체로 두고 [다시 시도] · [명령 출력 ▸] 은 그 아래 줄에 둡니다.
- **처음 한 번 묻는 카드** — 새 자식 세션 설정 · 자식 보고 값을 한 번도 바꾸지 않았으면 데스크톱 앱 세션의 [세션 도구] 맨 위에 「추천 설정으로 시작할까요?」 카드가 한 번 뜹니다. [추천대로 켜기] 는 세 가지를 켭니다: 자식 보고를 패널에 모아 둠 · 새 자식을 고정했다 끝나면 풂 · 사이드바 그룹으로 묶음(떼어 내기 · 첫 글 ultrathink 는 꺼진 채). [앱 그대로] 는 아무것도 바꾸지 않습니다. 어느 쪽이든 누르면 다시 뜨지 않습니다. 누르기 전엔 앱 그대로입니다.
- **새 자식 세션 미리보기** — [설정] 「새 자식 세션」 맨 위에 「미리보기 · 사이드바」 칸이 생겼습니다. 부모 세션이 자식 둘을 열었을 때 지금 값으로 사이드바가 어떻게 보이는지(고정 칸 · 그룹 · 떼어 낸 자리 · 자식 보고)를 작은 그림으로 보입니다. 스위치를 바꾸면 바로 바뀝니다.
- **md 잠금** — [설정] 「md 잠금」 묶음. 「md 잠금 보기 · 풀기」 를 켜면(처음엔 꺼짐) 잠금 폴더(처음 값 `<Claude 설정 폴더>/locks`)의 잠금마다 대상 · 남은 시간 · 주인 세션 · 할 일과 [풀기] 가 보입니다. [풀기] 는 파일을 지우지 않고 끝 시각을 지금으로 고쳐 씁니다. 주인 세션이 보관됐거나 끝났으면 차례 끝에 저절로 풉니다. 채팅으로 「잠금 풀어 줘」 를 보내지 않아도 됩니다.
- **깊은 세션 트리 보기** — 하위 세션 줄 밑에 그 아래 세션이 있으면 「› 아래 N」(입력 필요가 있으면 「입력 필요 N」)이 붙습니다. 누르면 깊이만큼 들인 줄로 폅니다.
- **위 세션 칸의 메인 줄** — 메인이 바로 위 세션이 아니면 「위 세션」 칸에 「메인」 줄([보내기] · [가기])이 생깁니다.
- **`>>위` 신호** — 글 끝에 `>>위`(또는 `>>up`)를 붙이면 차례가 끝날 때 답이 바로 위 세션으로 갑니다.
- **auto 세션의 고정 · 풀기** — auto 세션이 새 자식을 고정하거나 끝난 뒤 고정을 풀어야 할 때, 같은 세션 트리 위의 bypass 세션이 그 세션 차례 끝에 대신합니다. 위에 bypass 세션이 없으면 지금처럼 그대로입니다.
- **「붙잡힐 수 있음」 한 줄** — 받는 세션의 권한 모드가 보내는 세션과 다르면 [보내기] · 「전달」 · `>>` 의 지시 글 · 알림에 한 줄이 붙습니다. 막지는 않습니다.

### 바뀜
- **메인** — 메인은 그 세션 트리의 맨 위 오케입니다. 세션 트리마다 하나라 한 PC 에 여럿일 수 있습니다. `>>메인` · 「전달」 의 메인 · 역할 칩 · 관계 줄이 모두 이 뜻을 씁니다. 하위 세션이 없는 메인은 「역할 · 인계」 에서 [오케 풀기] 로 되돌립니다.
- **입력창 보내기는 위로만** — 「전달」 은 위 세션 · 메인만 고릅니다. 신호는 `>>위` · `>>메인`(`>>up` · `>>main`)입니다. `>>이름` 은 보내지 않고 한 줄로 알립니다. 그 밖 세션에는 Claude 에게 보내 달라고 하세요.
- **떼어 낸 세션 자리** — 패널 · 사이드바에서 직접 떼어 낸 세션은 이지 세션의 세션 트리에서도 맨 위로 갑니다. 저절로 떼어 낸 새 자식은 부모 밑에 그대로 둡니다. 떼어 낸 세션이 인계하면 뒤 차수가 맨 위 자리를 이어받습니다.
- **칸 수 표** — 칸 모서리의 주황 수를 눌러도 그 칸이 펴집니다.
- **「고정 · 보관」 칸** — 지금 상태(고정 · Remote Control · 끝남 표시)는 스위치, 할 일(정리 · 제목 정리 · 보관 · 떼어 내기)은 단추입니다. Remote Control 상태를 못 읽으면 그 스위치를 흐리게 두고 「상태 못 읽음」 을 적습니다. 끝남 표시를 켤 때만 한 번 묻습니다. VS Code · 터미널의 「정리 · 끝내기」 칸도 같습니다.
- **자식 보고 값 이름** — [설정] 「자식 보고」 의 「사이드 패널에 모아 둠」 은 「패널에 모아 둠」 입니다(좁은 패널에서 잘려서).
- **「세션 트리」** — 보낸 세션 관계 줄 · [설정] 풀이 · [인계] 지시 글이 세션 사이 위아래를 「세션 트리」 라는 말로 부릅니다.
- **fable 확인 카드** — Fable 5.2 요율로 고쳤습니다. 요금은 Opus 5.5 의 2배(정가 100만 토큰당 입력 $8 · 출력 $40)입니다. 구독이면 5시간 사용량을 Opus 5.5 보다 많이 씁니다.
- **`/fork` · `/rewind` 칩** — 데스크톱 앱에서 `/fork` 설명은 「이 대화를 새 세션으로 갈라 이어 감」 입니다. `/rewind` 는 입력창에 글이 남아 있으면 넣지 않고 「입력창 글을 비운 뒤 누르세요」 를 띄웁니다.
- **[정리] 지시 글** — 저절로 붙인 고정은 bypass 세션이 풉니다. auto 세션이면 같은 세션 트리 위의 bypass 세션이 대신 풉니다. 그런 세션이 없으면 고정은 그대로입니다.
- **첫 그리기 시간 기록** — 패널을 처음 그리는 데 걸린 시간을 자료 폴더 `diag/first-draw.json` 에 적습니다(최근 50줄 · 화면엔 안 보임). 다른 세션을 눌렀을 때 패널이 늦게 뜨는 까닭을 재려는 기록입니다.
- **VS Code ultrathink 칩** — 넣었으면 채운 단추로 보입니다(VS Code 테마의 단추 색).
- **보낸 세션 관계 알리기** — VS Code · 터미널의 [설정] 풀이에 「데스크톱 앱에서만 — 여기서 바꿔도 데스크톱 세션에 적용됩니다」 를 붙였습니다.

### 고침
- **인계한 세션 보관** — auto 세션이 인계한 뒤 자기 세션을 보관하려 할 때, 아직 붙은 새 세션이 있으면 막고 먼저 `detach_session` 으로 떼라고 알립니다. 보관하면 붙은 세션도 같이 보관되기 때문입니다. bypass 세션은 지금처럼 먼저 떼고 보관합니다.
- **보낸 세션 찾기** — 받은 글의 보낸 곳이 앱 세션 번호로만 적혀 있을 때 그 세션을 못 찾아 관계 줄이 빠지던 것을 고쳤습니다.

### 새로 생김
- **VS Code** — VS Code 의 Claude Code 확장(채팅 패널)에도 입력창 위 줄과 세션 패널이 뜹니다(확장 2.1.326 에서 확인). VS Code 세션은 데스크톱 앱 세션 트리 밖입니다. 그래서 데스크톱 앱이 있어야 되는 것은 채팅 옆 넓은 패널에선 흐리게 두고 까닭을 적습니다. 입력창 위 12줄 칸에선 뺍니다. 그 칸의 패널은 칸마다 한 줄인 목록입니다. 줄을 누르면 바로 아래에 펴집니다.
- **터미널** — 터미널의 `claude` 에도 입력창 위 줄(세션 패널 단추)과 글 꼴 패널이 생깁니다. 칸은 글 단추 목록, 고르기는 가로로 늘어선 단추, 스위치는 [켬] [끔] 단추입니다.
- **데스크톱 앱 밖 세션** — 지금 열린 VS Code · 터미널 세션이 「다른 세션」 칸의 「데스크톱 앱 밖 · 지금 열린 세션」 아래에 「VS Code」 · 「터미널」 표지와 [보내기] 를 달고 나옵니다. [가기] 는 데스크톱 앱 세션에만 있습니다. VS Code · 터미널 세션에선 이 칸에 지금 열린 데스크톱 앱 세션이 트리 차례대로 「메인」 · 「오케」 표지와 함께 나옵니다.
- **VS Code · 터미널에서 보내기** — [보내기] 는 권한 모드와 상관없이 바로 보냅니다. 그 세션에 닿지 못하면 Claude 에게 보내라는 지시 글을 입력칸에 넣습니다. VS Code · 터미널 세션이 보낸 글은 「도착」으로 보입니다.
- **VS Code · 터미널의 Remote Control · 내보내기** — 그 세션에 Claude Code 명령 `/remote-control` · `/export` 가 있으면 권한 모드와 상관없이 그 명령을 바로 돌립니다. 내보내기는 대화를 글 파일(`conversation-<날짜-시각>.txt`)로 다운로드 폴더에 저장합니다. 명령이 없으면 입력칸에 한 줄 부탁 글을 넣습니다.
- **세션 규칙** — [설정] 「메시지」 → 「세션 규칙(보내기 확인 · Claude 안내)」. 처음엔 켜져 있습니다. 데스크톱 앱 세션의 Claude 가 끝났거나 보관된 세션에 보내려 하면 막고 먼저 사용자에게 묻게 합니다. 한 번 대답하는 동안 세 번째 다른 세션에 보내려 할 때도 같습니다. 사용자가 답한 뒤의 같은 보내기는 통과합니다. 사용자가 글을 보낼 때 Claude 에게 짧은 규칙 줄도 붙입니다(모든 세션): 이어받은 세션의 첫 대답은 인계 자료만 읽고 보고하기, 메인 · 오케 세션은 일을 직접 하지 말고 판단하고 맡기기, 지시는 한 단계 아래로만. 데스크톱 앱 세션에서 인계 · 열기 · 위로 보내기를 말로 시키면 한 줄 안내가 붙습니다.
- **첫 글에 ultrathink** — [설정] 「새 자식 세션」 → 「첫 글에 ultrathink」. 처음엔 꺼져 있습니다. 이 세션이 새 세션을 열거나 하던 일을 새 세션으로 넘길 때, 보내는 글 맨 앞에 `ultrathink` 를 넣습니다.

### 바뀜
- **[세션 도구] 탭** — 「이 세션」 묶음(명령 · 어드바이저 · 고정 · 보관)이 맨 위로 왔습니다. 「고정 · 보관」 은 옛 「현재 세션」 칸입니다. 그 아래가 「세션 메시지」 · 「관리」 입니다. 처음엔 편 칸이 없습니다. 누른 칸이 그 줄 바로 아래 카드로 펴지고 다시 누르면 접힙니다(› · ˅). 카드 안은 줄마다 이름표와 단추입니다. 풀이는 **?** 뒤로 옮겼습니다. 「고정 · 보관」 은 표시(고정 · Remote Control) · 정리(정리 · 제목 정리) · 닫기(끝내기 · 보관 · 떼어 내기) 세 줄입니다.
- **칸 아랫줄** — 「보낸 N · 받은 N」 은 앱 도착 기록으로 셉니다(예전 「받은」 은 모인 메시지 수였습니다). 「하위 세션」 은 「N개 · 받은 N」, 「역할 · 인계」 는 컨텍스트 % 입니다. 제목 아래 줄에는 역할 칩과 「위 · <위 세션 제목>」 만 남겼습니다. 역할 칩은 「역할 · 인계」 카드를 펴고 접습니다. 「지금」 칸의 [보기] 는 펴기만 합니다.
- **화면 글** — 하위 줄 [받기 N] 은 [수락 N], 모인 메시지 묶음은 「받은 글 N」, 진행판 줄 이름은 「파일」 · 「새 줄」, 서브 세션의 진행판 줄은 「위 세션 것」 입니다. [가기] 는 채운 단추가 됐습니다.
- **인계** — [인계] 가 입력칸에 넣는 지시 글에, 새 세션이 첫 차례엔 인계 자료만 읽고 「나 · 연결」(무엇을 하는 세션인지 한 줄 · 도는 세션 · 끝난 세션)을 보고한 뒤 사용자 말을 기다리라는 줄이 더해졌습니다.
- **VS Code 알림** — 알림 대신 패널 맨 아래 한 줄로 보입니다. 패널이 닫혀 있으면 입력창 위 줄 끝에 나옵니다. 된 일에만 「✓」 가 붙습니다. 다음에 무엇을 누르면 사라집니다. `ultrathink` 무지개 글자는 VS Code 가 칠하는 색으로 그립니다.
- **VS Code · 터미널 세션이 보낸 글** — 「보낸 세션 관계 알리기」 를 켰으면 「세션 목록에서 찾지 못했습니다」 대신 데스크톱 앱 밖 VS Code · 터미널 세션이라고 Claude 에게 알립니다.

### 고침
- **곁가지의 다음 차수** — 곁가지 세션이 다음 차수를 직접 열면 패널이 둘을 사이드바와 위아래 거꾸로 그렸습니다. 이제 둘 다 열려 있는 동안 새 차수가 앞 차수 아래에 「이전 차수」 · 「다음 차수」 표지와 함께 놓입니다. 메인 · 오케 세션의 인계는 그대로입니다 — 새 차수가 자리와 하위 세션을 이어받습니다.

### 새로 생김
- **입력창 위 줄** — 세션 패널 단추와 고정 · `ultrathink` · advisor(모델 고르기 · 이 세션에서 불린 횟수 · 이지 컴팩트가 있으면 금액) · 전달(위 · 하위 · 형제 세션으로) · 화면 · 명령 칩(`/btw` · `/fork` · `/rewind` · `/recap` · 내보내기). 어느 칸을 둘지는 [설정]에서 고릅니다.
- **작업 줄의 `ultrathink`** — `ultrathink` 를 넣어 보낸 차례 동안 채팅 작업 줄 글 앞에 `ultrathink · ` 가 붙습니다.
- **세션 패널 [세션 도구] 탭** — 역할 칩(메인 · 오케 · 서브 · 단독)과 위 · 하위 · 형제 수, 할 것이 있을 때만 뜨는 「지금」 칸(입력 필요 · 모인 보고 · 받은 글 · 진행판 새 줄), 묶음 셋에 칸 아홉 — 세션 메시지(위 세션 · 형제 세션 · 다른 세션) · 관리(하위 세션 · 진행판 · 역할 · 인계) · 도구(명령 · 어드바이저 · 현재 세션). 누른 칸 하나만 펴집니다. 역할에서 안 쓰는 칸은 흐립니다. 칸 모서리 주황 수는 기다리는 것을 셉니다.
- **하위 세션** — 표지(끝남 · 입력 필요 · 7일 넘게 쉼 · 붙임) · 모인 보고 받기 · 보관 · 가기, 메인 · 오케는 ⋯ 에 보내기 · 정리 부탁 · 끝내기 · 일 합치기 · 보관 · 떼어 내기. 모두 보관은 Bypass permissions 에서만 한 번에 합니다(화면에 열린 세션은 건너뛰고 고정은 먼저 풂). 다른 모드에선 줄마다 보관합니다.
- **보고 꼴로** — 다섯 칸 보고 글(끝난 것 · 하는 중 · 막힌 것 · 기다리는 결정 · 다음)을 입력칸에 넣습니다. 답은 위 세션으로, 맨 위 세션이면 채팅에.
- **현재 세션** — 고정 · Remote Control 켜기 · 끄기 · 정리(메인 · 오케는 앞에 하위 세션 → 일 → 보고 세 줄) · 제목 정리 · 끝내기 · 보관 · 떼어 내기.
- **보내기 신호** — 글 끝에 `>>메인` · `>>이름` 을 붙이면 그 차례 끝 답이 그 세션으로 갑니다. ➤ 는 친 글만 보냅니다. Bypass permissions 세션은 직접 보냅니다. 그 밖의 모드에선 Claude 의 SendMessage 나 받는 세션 패널의 카드로 갑니다.
- **[설정] 탭** — 입력창 위 줄에 둘 것(미리보기와 함께) · 화면 · advisor · 새 자식 세션(저절로 고정 · 끝나면 고정 풀기 · 사이드바 그룹으로 묶기 · 저절로 떼어 내기 · 자식 보고 모아 두기) · 보낸 세션 관계 알리기 · 정리.
- **남은 자료를 휴지통으로** — 보관한 세션이 남긴 스크래치 폴더를 먼저 묻고 Windows 휴지통으로 옮깁니다. `.md` 가 가리키는 폴더는 뺍니다.
- **깨우는 값 카드** — 캐시가 식은 세션에 보낼 때 컴팩트하고 보내는 쪽이 싸면 두 값을 먼저 보입니다.
- **이지 컴팩트와 같이** — advisor 횟수 · 금액이 이지 컴팩트와 같은 값입니다. 입력창 위 여러 줄 가운데 이지 세션 줄이 맨 위에 옵니다.
