## [0.1.28] — 2026-11-19

0.1.27 은 공개하지 않아서 그 판에서 바뀐 것도 여기 같이 적습니다.

### 새로 생김
- **VS Code** — VS Code 의 Claude Code 확장(채팅 패널)에도 입력창 위 줄과 세션 패널이 뜹니다(확장 2.1.326 에서 확인). VS Code 세션은 데스크톱 앱 세션 나무 밖입니다. 그래서 데스크톱 앱이 있어야 되는 것은 채팅 옆 넓은 패널에선 흐리게 두고 까닭을 적습니다. 입력창 위 12줄 칸에선 뺍니다. 그 칸의 패널은 칸마다 한 줄인 목록입니다. 줄을 누르면 바로 아래에 펴집니다.
- **터미널** — 터미널의 `claude` 에도 입력창 위 줄(세션 패널 단추)과 글 꼴 패널이 생깁니다. 칸은 글 단추 목록, 고르기는 가로로 늘어선 단추, 스위치는 [켬] [끔] 단추입니다.
- **데스크톱 앱 밖 세션** — 지금 열린 VS Code · 터미널 세션이 「다른 세션」 칸의 「데스크톱 앱 밖 · 지금 열린 세션」 아래에 「VS Code」 · 「터미널」 표지와 [보내기] 를 달고 나옵니다. [가기] 는 데스크톱 앱 세션에만 있습니다. VS Code · 터미널 세션에선 이 칸에 지금 열린 데스크톱 앱 세션이 나무 차례대로 「메인」 · 「오케」 표지와 함께 나옵니다.
- **VS Code · 터미널에서 보내기** — [보내기] 는 권한 모드와 상관없이 바로 보냅니다. 그 세션에 닿지 못하면 Claude 에게 보내라는 지시 글을 입력칸에 넣습니다. VS Code · 터미널 세션이 보낸 글은 「도착」으로 보입니다.
- **VS Code · 터미널의 Remote Control · 내보내기** — 그 세션에 Claude Code 명령 `/remote-control` · `/export` 가 있으면 권한 모드와 상관없이 그 명령을 바로 돌립니다. 내보내기는 대화를 글 파일(`conversation-<날짜-시각>.txt`)로 다운로드 폴더에 저장합니다. 명령이 없으면 입력칸에 한 줄 부탁 글을 넣습니다.
- **세션 규칙** — [설정] 「메시지」 → 「세션 규칙(보내기 확인 · Claude 안내)」. 처음엔 켜져 있습니다. 데스크톱 앱 세션의 Claude 가 끝났거나 보관된 세션에 보내려 하면 막고 먼저 사용자에게 묻게 합니다. 한 번 대답하는 동안 세 번째 다른 세션에 보내려 할 때도 같습니다. 사용자가 답한 뒤의 같은 보내기는 통과합니다. 사용자가 글을 보낼 때 Claude 에게 짧은 규칙 줄도 붙입니다(모든 세션): 이어받은 세션의 첫 대답은 인계 자료만 읽고 보고하기, 메인 · 오케 세션은 일을 직접 하지 말고 판단하고 맡기기, 지시는 한 단계 아래로만. 데스크톱 앱 세션에서 인계 · 열기 · 위로 보내기를 말로 시키면 한 줄 안내가 붙습니다.
- **첫 글에 ultrathink** — [설정] 「새 자식 세션」 → 「첫 글에 ultrathink」. 처음엔 꺼져 있습니다. 이 세션이 새 세션을 열거나 하던 일을 새 세션으로 넘길 때, 보내는 글 맨 앞에 `ultrathink` 를 넣습니다.

### 바뀜
- **[세션 도구] 탭** — 「이 세션」 묶음(명령 · 어드바이저 · 고정 · 보관)이 맨 위로 왔습니다. 「고정 · 보관」 은 옛 「현재 세션」 칸입니다. 그 아래가 「세션 메시지」 · 「관리」 입니다. 처음엔 편 칸이 없습니다. 누른 칸이 그 줄 바로 아래 카드로 펴지고 다시 누르면 접힙니다(› · ˅). 카드 안은 줄마다 이름표와 단추입니다. 풀이는 **?** 뒤로 옮겼습니다. 「고정 · 보관」 은 표시(고정 · Remote Control) · 정리(정리 · 제목 정리) · 닫기(끝내기 · 보관 · 떼어 내기) 세 줄입니다.
- **칸 아랫줄** — 「보낸 N · 받은 N」 은 앱 도착 기록으로 셉니다(예전 「받은」 은 모인 메시지 수였습니다). 「하위 세션」 은 「N개 · 받은 N」, 「역할 · 인계」 는 컨텍스트 % 입니다. 제목 아래 줄에는 역할 칩과 「위 · <위 세션 제목>」 만 남겼습니다. 역할 칩은 「역할 · 인계」 카드를 펴고 접습니다. 「지금」 칸의 [보기] 는 펴기만 합니다.
- **화면 글** — 하위 줄 [받기 N] 은 [수락 N], 모인 메시지 묶음은 「받은 글 N」, 진행판 줄 이름은 「파일」 · 「새 줄」, 서브 세션의 진행판 줄은 「위 세션 것」 입니다. [가기] 는 채운 단추가 됐습니다.
- **인계** — [인계] 가 입력칸에 넣는 지시 글에, 새 세션이 첫 차례엔 인계 자료만 읽고 「나 · 연결」(무엇을 하는 세션인지 한 줄 · 도는 세션 · 끝난 세션)을 보고한 뒤 사용자 말을 기다리라는 줄이 더해졌습니다.
- **VS Code 알림** — 알림 대신 패널 맨 아래 한 줄로 보입니다. 패널이 닫혀 있으면 입력창 위 줄 끝에 나옵니다. 된 일에만 「✓」 가 붙습니다. 다음에 무엇을 누르면 사라집니다. `ultrathink` 무지개 글자는 VS Code 가 칠하는 색으로 그립니다.
- **VS Code · 터미널 세션이 보낸 글** — 「보낸 세션 관계 알리기」 를 켰으면 「세션 목록에서 찾지 못했습니다」 대신 데스크톱 앱 밖 VS Code · 터미널 세션이라고 Claude 에게 알립니다.

### 고침
- **곁가지의 다음 차수** — 곁가지 세션이 다음 차수를 직접 열면 패널이 둘을 사이드바와 위아래 거꾸로 그렸습니다. 이제 둘 다 열려 있는 동안 새 차수가 앞 차수 아래에 「이전 차수」 · 「다음 차수」 표지와 함께 놓입니다. 메인 · 오케 세션의 인계는 그대로입니다 — 새 차수가 자리와 하위 세션을 이어받습니다.

## [0.1.26] — 2026-11-18 · 첫 공개

### 새로 생김
- **입력창 위 줄** — 세션 패널 단추와 고정 · `ultrathink` · advisor(모델 고르기 · 이 세션에서 불린 횟수 · 이지 컴팩트가 있으면 금액) · 전달(위 · 하위 · 형제 세션으로) · 화면 · 명령 칩(`/btw` · `/fork` · `/rewind` · `/recap` · 내보내기). 어느 칸을 둘지는 [설정]에서 고릅니다.
- **작업 줄의 `ultrathink`** — `ultrathink` 를 넣어 보낸 차례 동안 채팅 작업 줄 글 앞에 `ultrathink · ` 가 붙습니다.
- **세션 패널 [세션 도구] 탭** — 역할 칩(메인 · 오케 · 서브 · 단독)과 위 · 하위 · 형제 수, 할 것이 있을 때만 뜨는 「지금」 칸(입력 필요 · 모인 보고 · 받은 글 · 진행판 새 줄), 묶음 셋에 칸 아홉 — 세션 메시지(위 세션 · 형제 세션 · 다른 세션) · 관리(하위 세션 · 진행판 · 역할 · 인계) · 도구(명령 · 어드바이저 · 현재 세션). 누른 칸 하나만 펴집니다. 역할에서 안 쓰는 칸은 흐립니다. 칸 모서리 주황 수는 기다리는 것을 셉니다.
- **하위 세션** — 표지(끝남 · 입력 필요 · 7일 넘게 쉼 · 붙임) · 모인 보고 받기 · 보관 · 가기, 메인 · 오케는 ⋯ 에 보내기 · 정리 부탁 · 끝내기 · 일 합치기 · 보관 · 떼어 내기. 모두 보관은 Bypass permissions 에서만 한 번에 합니다(화면에 열린 세션은 건너뛰고 고정은 먼저 풂). 다른 모드에선 줄마다 보관합니다.
- **보고 꼴로** — 다섯 칸 보고 글(끝난 것 · 하는 중 · 막힌 것 · 기다리는 결정 · 다음)을 입력칸에 넣습니다. 답은 위 세션으로, 맨 위 세션이면 채팅에.
- **현재 세션** — 고정 · Remote Control 켜기 · 끄기 · 정리(메인 · 오케는 앞에 하위 세션 → 일 → 보고 세 줄) · 제목 정리 · 끝내기 · 보관 · 떼어 내기.
- **보내기 신호** — 글 끝에 `>>메인` · `>>이름` 을 붙이면 그 차례 끝 답이 그 세션으로 갑니다. ➤ 는 친 글만 보냅니다. Bypass permissions 세션은 직접 보냅니다. 그 밖의 모드에선 Claude 의 SendMessage 나 받는 세션 패널의 카드로 갑니다.
- **[설정] 탭** — 입력창 위 줄에 둘 것(미리보기와 함께) · 화면 · advisor · 새 자식 세션(저절로 고정 · 끝나면 고정 풀기 · 사이드바 그룹으로 묶기 · 저절로 떼어 내기 · 자식 보고 모아 두기) · 보낸 세션 관계 알리기 · 정리.
- **남은 자료를 휴지통으로** — 보관한 세션이 남긴 스크래치 폴더를 먼저 묻고 Windows 휴지통으로 옮깁니다. `.md` 가 가리키는 폴더는 뺍니다.
- **깨우는 값 카드** — 캐시가 식은 세션에 보낼 때 컴팩트하고 보내는 쪽이 싸면 두 값을 먼저 보입니다.
- **이지 컴팩트와 같이** — advisor 횟수 · 금액이 이지 컴팩트와 같은 값입니다. 입력창 위 여러 줄 가운데 이지 세션 줄이 맨 위에 옵니다.
