easy-session

입력창 위 줄과 세션 패널을 직접 눌러 보는 안내서 · 0.1.31

easy-session 은 advisor · ultrathink 같은 Claude Code 기능을 입력창 위에서 바로 켜고 끕니다. 언제 불렀고 무엇을 했는지 · 얼마 들었는지도 보입니다. 하위 세션의 보고가 위 세션을 깨우기 전에 받을지 고르게 합니다. 세션이 늘면 메인 · 오케 같은 역할과 세션 트리로 정리합니다.

주제별 설명

①손쉽게 켜고 끄고 보이게

흔히는흔히 생각 깊이(노력)를 높게 정해 두고 씁니다. 정한 값은 다음 세션에도 남습니다[3]. 그러면 가벼운 차례도 깊게 생각합니다. advisor 를 켜고 끄려면 /advisor 를 치고 언제 불렀는지는 대화를 거슬러 올라가 찾습니다[1]. 얼마 들었는지는 /usage 로 따로 봅니다[1].

easy-session 으로는노력은 그대로 두고 깊게 생각할 차례에만 ultrathink 를 한 번 눌러 넣습니다. 데스크톱 앱 Code 탭에선 그 차례만 xhigh 로 생각하고 세션 노력 설정은 그대로입니다[3]. advisor 는 입력창 위에서 바로 켜고 끕니다. 부른 때 · 앞뒤에 한 일 · 횟수 · 금액이 보입니다.

②위로 가는 보고는 고를 때만

흔히는세션에서 새 세션을 열면 그 세션이 차례를 끝낼 때마다 데스크톱 앱이 그 보고를 연 세션에 넣어 줍니다. 연 세션이 쉬고 있었으면 보고를 읽느라 한 차례씩 돌고 그때마다 토큰이 듭니다.

easy-session 으로는보고를 따로 모아 관리합니다. 보고만 든 차례는 막고 「지금」 칸 · 하위 세션 칸에서 하나씩 보기 · 받기 · 지우기 · 모두 받기를 합니다. 받을 때 요청 한 번 값이 보입니다. 고른 보고만 받아 깨우는 차례 · 토큰이 줄어듭니다.

③>> — 이지 세션만의 명령

흔히는답을 다른 세션에 넘기려면 답을 받은 뒤 「이거 메인에 보내 줘」라고 한 번 더 부탁합니다. 그 부탁도 한 차례입니다.

easy-session 으로는글 끝에 >>위 · >>메인 을 붙이면 차례가 끝날 때 답이 위 세션 · 메인으로 갑니다. ➤ 는 친 글만 차례 없이 보냅니다.

④세션 관리

흔히는세션이 늘면 어느 세션이 일을 나누고 어느 세션이 맡는지 말로 정합니다. 무슨 일이 도는지는 세션을 하나씩 열어 보고 새 세션에 넘길 것은 인계 글로 손수 씁니다.

easy-session 으로는역할(메인 · 오케 · 서브 · 단독)과 세션 트리가 패널 하나에 보입니다. [인계] 한 번이면 다음 차수가 자리 · 하위 · 고정 · 진행판을 이어받고 끝난 세션에 보내려 하면 먼저 묻습니다.

직접 눌러 보기

위 장점을 화면 모형에서 차례대로 눌러 봅니다.

단계①②③④

1. advisor 켜고 끄기

왜/advisor 를 치지 않고 입력창 위에서 advisor 를 켜고 끄고 모델을 고릅니다.

보이는 것이 세션 메인에 걸리는 모델이면 그림이 서고 안 걸리면 회색으로 잡니다(메인 Opus 5.5 에 sonnet). fable 은 확인 카드가 먼저 뜹니다.

모형 밖 단추 — 실제 화면에는 없음

2. advisor 앞뒤 보기

왜부른 때와 앞뒤 일이 보여서 advisor 를 어느 일에 켜 둘지 정하기 쉽습니다.

보이는 것부를 때마다 어드바이저 칸에 시각 · 토큰 · 하던 일 · 그 뒤가 쌓이고 입력창 위 횟수가 오릅니다. 조언 내용은 읽지 않습니다.

모형 밖 단추 — 실제 화면에는 없음

3. ultrathink 쉽게

왜깊게 생각할 차례에만 낱말을 넣고 빼는 일을 한 번 누름으로 합니다.

보이는 것누르면 입력창 맨 앞에 무지개 ultrathink 가 들어가고 다시 누르면 빠집니다. 보내면 작업 줄이 「ultrathink · 」로 시작합니다.

모형 밖 단추 — 실제 화면에는 없음

4. 금액 표시

왜금액이 그 자리에 보여서 따로 셈하지 않고 고릅니다.

보이는 것입력창 위 advisor 횟수 · 금액(easy-compact 가 있을 때), 식은 세션에 보낼 때 ❄ 카드의 두 값, 모인 보고를 받을 때 요청 한 번 값이 보입니다.

숫자는 예시 · 가정입니다. Opus 5.5 요율(2026-11-19 가격 문서)로 셈했습니다 — 맨 아래 「예시 숫자」.

모형 밖 단추 — 실제 화면에는 없음

5. 위로 가는 보고는 고를 때만

왜세션에서 연 새 세션의 보고를 따로 모아 관리합니다. 위 세션을 깨우기 전에 받을지 고르니 깨우는 차례 · 토큰이 줄어듭니다.

보이는 것앱 그대로면 보고마다 위 세션이 한 차례를 돕니다. 모아 두면 「지금」 칸에 카드가 쌓이고 하나씩 보기 · 받기 · 지우기 · 모두 받기를 할 수 있습니다. [수락]할 때 한 번 돕니다.

켜는 곳: 설정 → 새 자식 세션 → 자식 보고 → 패널에 모아 둠(처음 한 번 묻는 카드의 [추천대로 켜기]도 이 값을 켭니다). 처음 값은 앱 그대로입니다.

모형 밖 단추 — 실제 화면에는 없음
보고 때문에 「화면 정리 4차」가 깬 차례 — 앱 그대로 0 · 모아 둠 0

6. >> 로 보내기

왜답을 받은 뒤 「이거 메인에 보내 줘」라고 한 번 더 부탁하지 않습니다.

보이는 것전달 칸에서 위 세션을 고르거나 글 끝에 >>위 를 붙이면 차례가 끝날 때 답이 위 세션으로 갑니다. >>메인 은 이 세션 트리의 메인으로 갑니다. ➤ 는 친 글만 차례 없이 보냅니다. 입력창 보내기는 위로만 갑니다.

모형 밖 단추 — 실제 화면에는 없음

7. 역할 · 세션 트리 · 인계

왜세션이 늘어도 어느 세션이 일을 나누고 어느 세션이 맡는지 역할과 세션 트리로 봅니다.

보이는 것세션을 누르면 역할 칩과 위 · 형제 · 하위 · 「지금」이 바뀝니다. [인계] 뒤 다음 차수가 자리 · 하위 · 고정 · 진행판을 이어받고 끝난 세션에 보내려 하면 먼저 묻습니다.

알아 둘 것

  • 권한 모드에 따라 다릅니다. 앱을 바꾸는 단추(고정 · 보관 · 떼어 내기 · 내보내기 · Remote Control · 보내기)는 Bypass permissions 세션에서 바로 처리합니다. 다른 모드에선 입력창에 한 줄 지시 글을 넣습니다. 그 글을 보내면 처리됩니다. auto 모드에선 플러그인이 직접 부른 앱 도구를 데스크톱 앱이 「Claude 가 부르게 하라」며 돌려보냅니다(앱 규칙 · Claude Code 2.1.325 에서 확인). 이 모형은 Bypass permissions 세션입니다.
  • VS Code · 터미널에도 입력창 위 줄과 세션 패널이 뜹니다. 데스크톱 앱 세션 트리 밖이라 고정 · 전달 칸과 위 · 형제 · 하위 세션 칸은 흐리거나 빠집니다. 보내기는 세션 패널에서 합니다.
  • 화면 언어는 설정 → 화면 · advisor → 언어 · Language(자동 · 한국어 · English)에서 고릅니다.
  • 금액은 고정 단가로 낸 어림입니다. 구독 요금제라면 요청이 얼마나 무거운지를 보는 값으로 읽으세요.
